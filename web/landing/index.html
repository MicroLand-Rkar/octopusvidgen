Run the studio in four commands

OctopusVidGen uses your own Claude Code, so there is nothing to sign up for.

  • Claude Code, signed in with a Claude subscription or an API key.
  • Node.js and Rust to build the studio and run its server.
  • Optional: Claude in Chrome, so picture styles can make images with Google Flow.
Terminal
$ git clone https://github.com/MicroLand-Rkar/octopusvidgen
$ cd octopusvidgen/web/app && npm install && npm run build
$ cd ../../server && cargo run --release
$ open http://127.0.0.1:8787
$

Questions

What people ask before their first film.

Ask on GitHub Issues

What does OctopusVidGen cost?

OctopusVidGen is free. Films run on your own Claude Code, so they count against your Claude plan or your API key.

Does the studio need an account?

No. There is no sign-up. The studio runs on your computer and keeps your films there.

Can I use the films for client work?

The films you make are yours. Some styles' rules are non-commercial: the Lemo-Opuscar style guides are CC BY-NC 4.0, and the onetake styles are for non-commercial use. Check a style before client work.

Which film lengths and sizes?

From 15 to 180 seconds, in 16:9, 9:16, 1:1 or 4:5.

How long does one film take to make?

Usually 10 to 20 minutes. Every frame is drawn and rendered on your computer.

The whole studio, free on GitHub

Open source. No account. Your films stay on your computer.
